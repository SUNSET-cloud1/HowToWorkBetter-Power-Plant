## 第 1 章 监盘与巡检

### 1.1 接班前 15 分钟「三看」：报警记录、趋势曲线、缺陷单
- **场景**：集控运行，交接班时；任意机组
- **成本要点**：时间约 15 分钟/班｜风险 无｜资源 无
- **收益要点**：建立本班设备状态基线，早发现隔夜变化，降低交班遗漏
- **证据**：B｜本厂运行规程「交接班制」（两票三制组成部分）
- **关联**：5.1

### 1.2 重点参数「同工况对比」：负荷/汽温/汽压/真空/瓦温瓦振 与昨日同期、额定值对比登记
- **场景**：集控运行，监盘班中；任意机组
- **成本要点**：时间 5–10 分钟/班｜风险 无｜资源 无
- **收益要点**：把「感觉正常」变成「有基线可查」，提前发现缓慢劣化
- **证据**：B｜本厂运行规程；C｜参数劣化趋势分析类期刊论文（《中国电力》《热力发电》）
- **关联**：1.7

### 1.3 巡检「听摸看闻」四步法＋工具：测温枪、听针、手电、测振仪随身
- **场景**：集控运行/设备巡检岗，就地巡检；任意机组
- **成本要点**：时间每次 40–60 分钟｜风险 无｜资源 无（工具自备）
- **收益要点**：轴承异音、局部过热、渗漏、异常气味多靠就地发现，是 DCS 看不到的信息源
- **证据**：B｜本厂运行规程「巡回检查制」；A｜GB 26164.1-2010 安全防护相关要求
- **关联**：5.1

### 1.4 交接班「隐患交底」：未闭环缺陷、临时措施、薄弱设备 口头＋书面双交
- **场景**：集控运行/检修班组，交接班时
- **成本要点**：时间 5 分钟/班｜风险 无｜资源 无
- **收益要点**：防止「以为对方知道」导致措施漏执行；安全事故多发生在交接不清后
- **证据**：B｜本厂运行规程「交接班制」；A｜GB 26860-2011/GB 26164.1-2010 工作票与交接相关要求
- **关联**：5.1

### 1.5 报警分级响应：事故/预告/提醒三类报警，明确处置时限与升级路径
- **场景**：集控运行，监盘时；任意机组
- **成本要点**：时间按级别 1–30 分钟｜风险 低（按流程处置）｜资源 必要时协调值长/专工
- **收益要点**：把「响铃就慌」变成「分级处置」，避免漏处理重要报警
- **证据**：B｜本厂运行规程、DCS 报警定值说明书
- **关联**：2.1、5.7

### 1.6 定期工作「日历化」：疏水、排污、辅机切换、备用设备定期试验 按日历执行并打勾
- **场景**：集控运行，班中；任意机组
- **成本要点**：时间 10–20 分钟/项｜风险 低｜资源 无
- **收益要点**：备用设备「备而可用」，防备用转备用失效；属两票三制「设备定期试验轮换制」
- **证据**：B｜本厂运行规程「设备定期试验轮换制」
- **关联**：5.1

### 1.7 用趋势看劣化：调 24h/7d 趋势判断劣化速率，区分「变送器漂移」与「真实劣化」
- **场景**：集控运行，参数异常时；任意机组
- **成本要点**：时间 5–10 分钟｜风险 无｜资源 无
- **收益要点**：先判断「表真不真、涨多快」，再决定处置级别；避免误停机或漏掉真劣化
- **证据**：B｜本厂运行规程、DCS 说明书；C｜参数趋势预警类论文
- **关联**：1.8、3.2、5.7

### 1.8 参数越限「先对三表」：DCS 值、就地表计、冗余测点 三者比对后再定处置
- **场景**：集控运行，参数越限报警时
- **成本要点**：时间 3–5 分钟｜风险 低｜资源 必要时联系热工校验
- **收益要点**：大量「假报警」来自测点故障；先确认测点真实性可避免误操作
- **证据**：B｜本厂运行规程、热工仪表管理制度
- **关联**：1.7、2.1

## 第 2 章 缺陷与消缺

### 2.1 缺陷三级分类：一类（紧急，威胁安全/可能非停）、二类（重大，需停机或降负荷处理）、三类（一般，可计划处理）
- **场景**：集控运行/检修，缺陷发现与受理时
- **成本要点**：时间 5 分钟判定｜风险 判定错误直接影响处置方式｜资源 与值长/检修确认
- **收益要点**：分类决定「现在处理还是计划处理」，是两票管理的前提
- **证据**：B｜本厂《设备缺陷管理制度》、DL/T 838-2017 检修分类
- **关联**：5.1

### 2.2 缺陷单「五要素」：设备名称/部位/现象/发现时间/影响评估
- **场景**：运行巡检发现缺陷、检修接单时
- **成本要点**：时间 2–3 分钟填写｜风险 无｜资源 无
- **收益要点**：让检修一次带对工器具与备件，减少返工和二次往返
- **证据**：B｜本厂《设备缺陷管理制度》
- **关联**：2.1

### 2.3 高温高压管道/阀门泄漏「先隔离、再报告、后处理」：隔离范围按系统图确认
- **场景**：集控运行，巡检或监盘发现泄漏时；汽水系统
- **成本要点**：时间 10–30 分钟｜风险 高（泄漏扩大/烫伤）｜资源 需要办理工作票、确认隔离边界
- **收益要点**：先控住「漏点」再谈「修」，防止汽水喷出伤人、扩大损伤
- **证据**：A｜GB 26164.1-2010 工作票制度（检修隔离要求）；B｜本厂运行规程事故处理章节
- **关联**：5.1、5.7

### 2.4 渗漏点「台账打卡」：记录位置/介质/首次发现时间/复发次数，跟踪复发率
- **场景**：运行/检修，日常巡检与消缺
- **成本要点**：时间 10 分钟/周维护台账｜风险 无｜资源 无
- **收益要点**：小渗漏不台账化就会「漏成大事」；复发率数据支撑根因分析
- **证据**：C｜渗漏治理经验总结、可靠性分析报告（《中国电力》等）
- **关联**：2.6

### 2.5 消缺后「双确认」：检修自检合格 ＋ 运行验收，试运时间按规程不少于规定值
- **场景**：检修消缺完工、运行验收时
- **成本要点**：时间 0.5–2 小时试运｜风险 低｜资源 检修、运行双方到位
- **收益要点**：杜绝「消了又坏」；试运是发现返工的最后关口
- **证据**：B｜DL/T 838-2017 检修验收要求、本厂检修管理规程
- **关联**：4.5

### 2.6 重复缺陷「根因分析」：同一部位 3 次及以上缺陷必须写根因分析报告（材质/工况/安装）
- **场景**：检修专业，缺陷统计分析时
- **成本要点**：时间 1–2 小时/份报告｜风险 无｜资源 需调历史数据
- **收益要点**：治本不治标；一次根因分析常省下多次重复消缺
- **证据**：C｜根因分析（RCA）实践论文；B｜DL/T 838-2017 检修记录要求
- **关联**：2.4

### 2.7 隐蔽部位「借停机窗口预防性检查」：内窥、测厚、着色探伤安排进 C/D 修
- **场景**：检修，机组检修计划编制时
- **成本要点**：时间 随检修窗口｜风险 低｜资源 需检测单位/仪器协调
- **收益要点**：看不见的部位（汽缸内部、管道弯头）是爆管/断裂高发区，停机机会是唯一低成本窗口
- **证据**：B｜DL/T 838-2017、金属技术监督要求（DL/T 438）
- **关联**：4.8

## 第 3 章 操作与调整

### 3.1 重大操作「预演＋唱票」：启停机、并网、切旁路等操作前桌面推演，执行中逐项唱票复诵
- **场景**：集控运行，重大操作前
- **成本要点**：时间 15–30 分钟预演｜风险 低（操作本身按票执行）｜资源 值长、机组长到位
- **收益要点**：操作票是「防错」的最后一道闸，唱票复诵把误操作率压到最低
- **证据**：A｜GB 26860-2011/GB 26164.1-2010 操作票制度；B｜本厂运行规程
- **关联**：5.1

### 3.2 负荷升降「速率受控」：按规程规定速率（滑压运行参数曲线）调整，控制汽温汽压波动
- **场景**：集控运行，负荷调整时
- **成本要点**：时间 随调整过程｜风险 中（速率失控→汽温汽压大幅波动）｜资源 与调度沟通负荷指令
- **收益要点**：汽温骤变是金属疲劳、汽缸温差裂纹的主因；速率受控是最廉价的寿命保护
- **证据**：B｜DL/T 610-2017《300MW级锅炉运行导则》、DL/T 611-2017《300MW级汽轮机运行导则》、本厂运行规程
- **关联**：1.7、5.7

### 3.3 燃烧调整「风煤配比微调」：以氧量/炉膛负压/CO 为基准，兼顾效率与结焦、NOx
- **场景**：集控运行，燃烧工况调整时
- **成本要点**：时间 10–20 分钟/次｜风险 低（微调幅度内）｜资源 必要时联系热工/专工
- **收益要点**：风煤比失配直接烧钱（排烟损失、不完全燃烧）和结焦；微调几乎零成本
- **证据**：B｜DL/T 610-2017；C｜燃烧优化论文（《热力发电》《中国电力》）
- **关联**：3.4、3.8

### 3.4 吹灰「按温差决策」：以受热面壁温差/排烟温度/减温水流量趋势决定吹灰频次
- **场景**：集控运行/锅炉专业，运行中
- **成本要点**：时间 每次吹灰 30–60 分钟蒸汽/空气消耗｜风险 低（控制汽温波动）｜资源 协调吹灰系统投入
- **收益要点**：欠吹→排烟温度高、爆管风险；过度吹→受热面吹损；按数据定频次两头都省
- **证据**：B｜DL/T 610-2017、锅炉厂家说明书；C｜受热面吹灰优化论文
- **关联**：3.3

### 3.5 凝汽器「真空与端差管理」：定期真空严密性试验、查漏、胶球清洗
- **场景**：集控运行/汽机专业，运行中
- **成本要点**：时间 严密性试验 30–60 分钟/月｜风险 低｜资源 查漏需协调停机窗口或在线检漏
- **收益要点**：真空每降 1kPa 煤耗上升明显；端差管理是最直接的节能抓手
- **证据**：B｜DL/T 611-2017、本厂运行规程；C｜凝汽器查漏与节能论文
- **关联**：3.2

### 3.6 制粉系统「防爆防堵」：磨出口温度、煤粉细度、风速控制，启停磨顺序
- **场景**：集控运行/锅炉专业，制粉系统运行与启停时
- **成本要点**：时间 随操作｜风险 高（煤粉爆炸/堵磨）｜资源 协调输煤、燃烧调整
- **收益要点**：制粉爆炸是火电典型事故；控住出口温度与风速是低成本高收益的保命操作
- **证据**：A｜《防止电力生产事故的二十五项重点要求》(2023)「防止锅炉制粉系统爆炸」；B｜DL/T 610-2017、磨煤机厂家说明书
- **关联**：5.7

### 3.7 深度调峰「低负荷稳燃预案」：确认最低稳燃负荷、等离子/微油枪备用、燃烧器摆角配合
- **场景**：集控运行，低负荷/深调时段
- **成本要点**：时间 预案编制一次性投入＋每班确认｜风险 高（灭火放炮）｜资源 等离子/油枪系统维护协调
- **收益要点**：深调是趋势，稳燃预案不备好就可能灭火放炮非停；有预案才能接得住调度指令
- **证据**：A｜《防止电力生产事故的二十五项重点要求》(2023)「防止锅炉灭火放炮」；B｜本厂运行规程最低稳燃负荷规定
- **关联**：5.3、5.7

### 3.8 汽温调整「减温水与燃烧配合」：以燃烧侧为主、减温水为辅，避免大流量减温水引起汽温骤降/水塞
- **场景**：集控运行，汽温调节时
- **成本要点**：时间 随调节过程｜风险 中（减温水猛增→汽温骤降、水塞）｜资源 无
- **收益要点**：靠燃烧调汽温省煤省水，靠减温水硬压是「用危险换指标」
- **证据**：B｜DL/T 610-2017、DL/T 611-2017；C｜汽温控制优化论文
- **关联**：3.3

### 3.9 启停操作「条件清单」：冲转、并网、解列、停炉/停机前按条件清单逐项确认
- **场景**：集控运行，机组启停全过程
- **成本要点**：时间 每次启停 10–20 分钟核对清单｜风险 高（条件不满足强行操作→设备损坏）｜资源 值长、机组长、检修到场配合
- **收益要点**：冲转/并网条件缺一项就「抢一次」，代价是轴系损伤或误并列；清单核对是启停性价比最高的动作
- **证据**：B｜DL/T 610-2017、DL/T 611-2017（启停条件与顺序）、本厂运行规程启停章节
- **关联**：3.1、5.7

## 第 4 章 检修与验收

### 4.1 检修「按 DL/T 838 定级」：A/B/C/D 修分级，检修项目按状态评估确定，避免过修与失修
- **场景**：设备检修专业，检修计划编制时
- **成本要点**：时间 计划编制 1–3 天｜风险 低（定级影响工期与费用）｜资源 需运行、技术监督数据支持
- **收益要点**：过修烧钱、失修埋雷；定级合理是检修性价比的总开关
- **证据**：B｜DL/T 838-2017《发电企业设备检修导则》
- **关联**：2.7、4.2

### 4.2 关键工序「W/H 点见证」：设置质量见证点（W）/停工待检点（H），未见证不得进入下道工序
- **场景**：检修实施阶段，关键工序前后
- **成本要点**：时间 每次见证 0.5–1 小时｜风险 低｜资源 质检/监理/运行三方到位
- **收益要点**：H 点不设＝返工时才知道坏了；见证点是最便宜的质量保险
- **证据**：B｜DL/T 838-2017、本厂检修质量管理
- **关联**：4.5

### 4.3 检修记录「一图一表一数据」：修前修后间隙/振动/温度数据对比表，验收有量化依据
- **场景**：检修实施与验收阶段
- **成本要点**：时间 每台设备 10–20 分钟记录｜风险 无｜资源 无
- **收益要点**：数据对比让「修没修好」可量化，也是下次检修和根因分析的基础
- **证据**：B｜DL/T 838-2017 检修记录要求
- **关联**：4.2、2.6

### 4.4 螺栓紧固「力矩标准化」：重要法兰/联轴器螺栓按力矩要求分级紧固，标注力矩值
- **场景**：检修实施阶段，汽机/锅炉重要结合面
- **成本要点**：时间 每处增加 5–10 分钟｜风险 低（按要求执行）｜资源 力矩扳手配置
- **收益要点**：欠紧漏汽、过紧断裂；力矩管理是高温高压管道泄漏的头号预防措施
- **证据**：B｜设备厂家检修工艺、本厂检修规程
- **关联**：2.3、4.8

### 4.5 试运「分部→整体」流程：单体试运、分部试运、整套启动逐级验收，冷态/热态标准分开
- **场景**：检修完工后，试运验收阶段
- **成本要点**：时间 分部试运 2–8 小时｜风险 低（逐级把关）｜资源 运行、检修、热工共同到场
- **收益要点**：跳过分部试运直接整套启动，一次泄漏/振动异常就拖垮整个启动窗口
- **证据**：B｜DL/T 838-2017 检修验收与试运要求
- **关联**：2.5

### 4.6 备件「寿命台账」：关键备件（轴承、密封、阀门内件）库存、寿命周期、更换记录管理
- **场景**：检修专业/物资管理，备件管理
- **成本要点**：时间 月度盘点 1–2 小时｜风险 无｜资源 与物资部门联动
- **收益要点**：急件等备件=非停时间；台账清楚才能「该换就换、不误事也不囤死」
- **证据**：B｜本厂物资与检修管理；C｜可靠性管理经验总结
- **关联**：2.1

### 4.7 交叉作业「动火＋隔离双管控」：动火票、安全隔离、监护人到位，检修与运行交叉界面清晰
- **场景**：检修期间，动火作业与运行设备交叉时
- **成本要点**：时间 动火前检查 10–20 分钟｜风险 高（火灾/误动运行设备）｜资源 监护人、消防措施
- **收益要点**：动火失控是检修期火灾主因；隔离不清会误碰运行系统
- **证据**：A｜GB 26164.1-2010 动火作业要求；B｜本厂动火票管理制度
- **关联**：5.1

### 4.8 金属监督「重点项目清单」：高温高压焊口、蠕变测点、管道壁厚按周期检测，纳入技术监督
- **场景**：检修/技术监督专业，停机检修窗口
- **成本要点**：时间 随检测项目（测厚/探伤）｜风险 低｜资源 需检测单位与仪器协调
- **收益要点**：高温管道爆漏是二十五项反措重点防范事故；金属监督是「用检修窗口换十年安稳」
- **证据**：A｜《防止电力生产事故的二十五项重点要求》(2023)「防止锅炉/汽水管道爆漏」；B｜DL/T 438《火力发电厂金属技术监督规程》
- **关联**：2.7

## 第 5 章 安全与应急

### 5.1 两票三制「红线执行」：工作票/操作票、交接班制/巡回检查制/设备定期试验轮换制，票面措施逐项落实
- **场景**：所有运行/检修作业；全天候
- **成本要点**：时间 办票 10–30 分钟/张｜风险 无（本身就是防风险）｜资源 运行、检修双方配合
- **收益要点**：绝大多数人身与设备事故源于「图省事跳过流程」；两票三制是零成本保命条款
- **证据**：A｜GB 26860-2011、GB 26164.1-2010 工作票/操作票制度；B｜本厂两票管理制度
- **关联**：1.1、1.3、1.4、1.6、2.1、3.1

### 5.2 安全交底「三讲一落实」：讲任务、讲风险、讲措施，落实到人签字确认
- **场景**：检修开工前、运行操作前
- **成本要点**：时间 5–10 分钟/次｜风险 无｜资源 无
- **收益要点**：交底不清是「不知道风险就干活」的源头；签字让每个人都过脑一遍
- **证据**：B｜集团/本厂安全管理要求（安全交底制度）
- **关联**：5.1

### 5.3 应急演练「每年一次全覆盖」：全厂停电、火灾、汽轮机超速/振动大、锅炉爆管等预案演练并复盘
- **场景**：运行/检修全员，年度计划
- **成本要点**：时间 每场 2–4 小时/年｜风险 低（桌面+实操结合）｜资源 需协调生产安排
- **收益要点**：真事故来临时没有时间查规程；演练过的动作才做得出来
- **证据**：A｜《生产安全事故应急预案管理办法》（应急管理部令）、电力安全生产监督管理办法演练要求；B｜本厂应急预案
- **关联**：5.7

### 5.4 有限空间作业「先通风、再检测、后作业」：氧含量/有毒气体检测合格方可进入，全程监护
- **场景**：检修，进入凝汽器、烟道、磨煤机、水箱等有限空间
- **成本要点**：时间 检测 15–30 分钟/次｜风险 高（缺氧/中毒）｜资源 检测仪、监护人
- **收益要点**：有限空间事故「一人晕倒众人救、救一个倒一个」；检测+监护是唯一正确顺序
- **证据**：A｜《工贸企业有限空间作业安全规定》（应急管理部令第13号）；B｜本厂有限空间管理制度
- **关联**：5.2

### 5.5 高处作业「脚手架验收」：搭设验收牌、安全带高挂低用、临边防护
- **场景**：检修，锅炉本体、烟道等高处作业
- **成本要点**：时间 验收 10–20 分钟｜风险 高（坠落）｜资源 架子工、验收人员
- **收益要点**：高处坠落是检修期第一杀手；验收牌不挂＝安全谁都不负责
- **证据**：A｜GB 26164.1-2010 高处作业章节；B｜本厂脚手架管理制度
- **关联**：5.2

### 5.6 电气操作「五防闭锁不解除」：防误闭锁装置运行中不得解锁，解锁须履行审批
- **场景**：电气运行/检修，倒闸操作时
- **成本要点**：时间 操作时间略增｜风险 无（防误本身是保险）｜资源 需审批流程
- **收益要点**：误操作（带负荷拉刀闸等）后果是人身伤亡；解锁审批是最后一道闸
- **证据**：A｜GB 26860-2011 操作管理要求；B｜本厂五防管理制度
- **关联**：5.1

### 5.7 事故处置「先保人身、再保设备、后保电量」：跳闸后按规程顺序处置，防止事故扩大
- **场景**：集控运行，机组跳闸/异常时
- **成本要点**：时间 按处置流程｜风险 高（处置顺序错误扩大事故）｜资源 值长统一指挥
- **收益要点**：顺序错了小事故变大事故；先把「人」和「设备」稳住，电量最后考虑
- **证据**：B｜本厂运行规程事故处理章节；A｜《防止电力生产事故的二十五项重点要求》(2023)
- **关联**：5.3、2.3

### 5.8 二十五项反措「年度对照自查」：逐条对照检查整改闭环，防典型事故重演
- **场景**：运行/检修/技术监督，年度安全计划
- **成本要点**：时间 集中自查 1–2 天/年｜风险 无｜资源 需多专业参与
- **收益要点**：反措每一条背后都是真实事故；对照自查是最便宜的「买教训清单」
- **证据**：A｜《防止电力生产事故的二十五项重点要求》(2023)
- **关联**：4.8、3.6、3.7

## 第 6 章 学习与成长

### 6.1 技能矩阵「岗位对标」：按岗位培训要求建立个人技能清单，逐项考评定级
- **场景**：新员工/转岗人员，职业发展
- **成本要点**：时间 建立 1–2 小时，季度更新｜风险 无｜资源 无
- **收益要点**：知道自己「还差什么」比盲目学习省时间；对标才能谈晋升
- **证据**：B｜本厂培训管理制度；C｜岗位胜任力研究
- **关联**：6.7

### 6.2 事故案例「错题本」：把误操作、异常处置写成案例卡片，定期复盘
- **场景**：运行/检修个人，日常积累
- **成本要点**：时间 每案例 15–30 分钟｜风险 无｜资源 无
- **收益要点**：别人的事故是最好的教材；写一遍胜过读十遍
- **证据**：C｜案例教学与复盘实践（行业培训经验）
- **关联**：6.8

### 6.3 仿真机「每月一练」：重点练启停、事故处理，记录评分改进
- **场景**：集控运行人员，技能保持
- **成本要点**：时间 每月 2–4 小时｜风险 无（仿真无风险）｜资源 仿真机排班
- **收益要点**：事故处理不敢在真机上练；仿真机的错误是免费的
- **证据**：B｜本厂仿真培训计划；C｜仿真培训有效性论文
- **关联**：5.7

### 6.4 规程变更「季度跟踪」：反措、规程、定值变更及时学习并签字确认
- **场景**：运行/检修全员，制度变更时
- **成本要点**：时间 每次 0.5–1 小时｜风险 无｜资源 无
- **收益要点**：按旧规程操作=拿老地图开新车；变更签字是安全责任边界
- **证据**：B｜本厂规程管理制度；A｜标准/反措更新须执行新版
- **关联**：5.8

### 6.5 老师傅「绝活 OPL」：把经验固化为 One Point Lesson，纳入班组培训
- **场景**：检修/运行班组，经验传承
- **成本要点**：时间 每篇 30–60 分钟｜风险 无｜资源 无
- **收益要点**：老师傅退休带走的经验是最贵资产；OPL 让绝活留在班组
- **证据**：C｜精益管理与 OPL 实践（行业经验）
- **关联**：6.2

### 6.6 新技术「跟踪清单」：DCS 优化、AI 预警诊断、数字孪生等应用案例收集评估
- **场景**：技术骨干/专工，技术储备
- **成本要点**：时间 每月 1–2 小时｜风险 无｜资源 无
- **收益要点**：新技术（如 AI 预警）是「把老师傅经验变成系统能力」，早跟踪早受益
- **证据**：C｜《中国电力》《热力发电》等期刊论文、行业技术报告
- **关联**：6.1

### 6.7 取证与继续教育「规划清单」：特种作业证、注册类证书、职称评审时间表
- **场景**：个人职业发展，年度规划
- **成本要点**：时间 备考与考试投入｜风险 无｜资源 培训与考试费用
- **收益要点**：持证是岗位资格底线，职称是晋升硬通货；早规划不误窗口期
- **证据**：A｜《特种作业人员安全技术培训考核管理规定》；B｜本厂任职资格要求
- **关联**：6.1

### 6.8 Anki「规程卡片化」：定值、流程、反措要点做成卡片，碎片时间复习
- **场景**：个人学习，碎片时间
- **成本要点**：时间 制卡 10–20 分钟/组，复习 5–10 分钟/天｜风险 无｜资源 无
- **收益要点**：定值记不住=监盘心里没底；间隔重复是性价比最高的记忆方式
- **证据**：C｜间隔重复与主动回忆学习科学研究；B｜本厂培训考核要求
- **关联**：6.2
