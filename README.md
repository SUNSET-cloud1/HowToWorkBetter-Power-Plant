# ZM:PowerPlant —— 火电运检「如何活得更好」指南 Skill

## 1. 项目解决什么问题

火电厂运行、检修一线人员每天面对大量「该不该做、先做哪件」的决策：参数异常要不要停机、缺陷现在处理还是计划处理、检修做到什么程度、先学什么最有用。这类问题没有标准答案，但往往存在「有权威依据、按性价比排序」的最优解 —— 而一线人员最缺的是时间和精力去逐条翻规程、查标准。

本项目是一个可开源的 Agent Skill，用《如何活得更好》式的性价比框架，把一线运检经验组织成结构化条目库：



* 每条建议讲清「花掉什么（成本）/ 换回什么（收益）/ 证据多硬（A/B/C）」；

* 只引用权威来源（GB 国标、DL/T 行标、《电力安全工作规程》、《防止电力生产事故的二十五项重点要求》、厂家技术文件、期刊论文），不堆砌没出处的经验；

* 让运检人员用最少时间判断「该不该做、先做哪件」，并让 AI 助手按统一逻辑回答问题：**查得到就引条目，查不到就说查不到**，不编造结论。

## 2. 主要功能



* **决策式指南库**：6 大场景 48 条建议（监盘与巡检 / 缺陷与消缺 / 操作与调整 / 检修与验收 / 安全与应急 / 学习与成长），章内按性价比排序，每条含场景、动作、成本、收益、证据等级及来源、说人话版（7 字段模板）

* **证据分级体系**：A/B/C 三级（强制条款 / 行业规程与厂家文件 / 论文经验），配套权威来源清单与引用规范（`references/evidence-sources.md`）

* **AI 问答调用逻辑**：解析问题四要素（设备 / 现象 / 动作 / 岗位）→ 检索目录 → 按风险紧迫度与性价比排序 → 命中按模板展开；未命中如实说明并给出最相近条目与建议来源

* **多形态输出**：Markdown 回答（默认）、交互式 HTML 指南页（图形界面：搜索、按章筛选、条目展开 / 折叠）、PDF 导出、Anki 卡片（TSV/CSV，每行「正面 \t 背面」）、网页抓取核验公开标准条文

* **零依赖**：纯文档型 Skill，无脚本、无第三方运行时依赖；可作为本地 Agent Skill 加载，也可按 `agents/openai.yaml` 引入 OpenAI Agents 兼容平台

## 3. 安装方法

本项目是 Agent Skill，安装 = 把 `skills/Power-Plant` 目录放到 Skill 能发现的位置。

**方式一：本地 Agent 环境**



1. 将 `skills/Power-Plant` 整个目录复制到 Skill 根目录（例如 `<环境>/workspace/.user_skills/Power-Plant`），或保留在项目内 `skills/` 下供引用；

2. 保持目录结构完整，`SKILL.md`、`agents/`、`references/` 缺一不可：



```
skills/Power-Plant/

├── SKILL.md                      # Skill 入口：AI 调用逻辑、条目模板、证据等级、支持形态

├── agents/

│   └── openai.yaml               # OpenAI agents 配置（name/description/instructions/model/tools）

└── references/

&#x20;   ├── framework.md              # 目录框架：6 章 48 条，每条含场景/成本/收益/证据提示

&#x20;   ├── evidence-sources.md       # 证据来源清单与引用规范（A/B/C 定义）

&#x20;   └── examples.md               # 5 个完整问答示例（含「未命中」处理演示）
```



1. （可选）用官方校验脚本检查结构：



```
python quick\_validate.py skills/Power-Plant

\# 预期输出：Skill is valid!
```

**方式二：OpenAI Agents 兼容平台**



* 按 `agents/openai.yaml` 导入该 Skill（含 name /description/instructions /model/tools）。

**可选依赖（非必需）**



* Anki 桌面端：导入生成的 TSV/CSV 记忆卡片；

* PDF / HTML 导出能力：用于输出 PDF 与交互式指南页（由运行环境既有工具提供，Skill 本身不捆绑脚本）。

## 4. 使用方法

向已加载该 Skill 的助手直接提问运检决策问题，例如：



* 「#1 瓦温缓慢上涨要不要立即停机？」

* 「磨煤机出口温度偏高还能继续运行吗？」

* 「汽轮机冲转前要确认哪些条件？」

* 「循环水泵大修后试运验收看什么？」

* 「凝汽器真空偏低先查什么？」

助手按 SKILL.md「AI 调用逻辑」处理：解析问题 → 查 `references/framework.md` 定位条目 → 按风险紧迫度（安全与应急 > 操作与调整 > 监盘与巡检 > 缺陷与消缺 > 检修与验收 > 学习与成长）与章内性价比排序 → **命中则按 7 字段模板展开并标注证据等级；未命中则如实说明「指南未覆盖」，给出最相近条目与建议来源，不编造**。

**输出形态切换**：在提问时附加要求即可，例如「导出成 PDF」「做成 Anki 卡片」「生成一个可搜索的 HTML 页面」。

## 6. 指南站（交互式 HTML）

项目附带一个单文件自包含的交互式指南站，把 48 条内容做成可直接打开的网页：

* **入口**：`site/火电运检指南站.html` —— 双击用浏览器打开即可，无需服务器、无外部数据依赖（字体走 CDN，断网仍可读）。
* **功能**：在线检索（关键词 + 章节 + 证据等级筛选）、目录（按章浏览并跳转定位）、术语表（28 个高频术语）、核实记录（证据来源 8 大类 38 项与 A/B/C 分级规则）、6 篇长文、打勾清单（待办 / 收藏 / 已做到，数据存本地浏览器 localStorage）、关于页；顶部导航为 hash 路由多视图。
* **下载区**：`site/download/` 内含指南全文的排版版本 —— `指南全文.html`、`指南全文.pdf`、`指南全文.epub`，随版本更新。
* 指南站与 Skill 数据同源（均由 `references/framework.md` 的 48 条条目生成），口径一致。

## 验证与测试



* 官方校验：`python quick_validate.py skills/Power-Plant` → **Skill is valid!**

* 覆盖测试：用运行处置、启停操作、检修验收、节能调整、未命中五类问题走查调用逻辑；测试中发现「启停操作」场景覆盖不足，据此补充了条目 **3.9 启停操作「条件清单」**，并明确「章内按性价比排序」规则。
